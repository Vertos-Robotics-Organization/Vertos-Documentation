# Quickstart

This Quickstart walks you through everything needed to get up and running with your device. It covers:

* **Assembly** – step-by-step instructions for putting the hardware together.
* **Wiring** – guidance on making correct power and signal connections.
* **Vendor Dependencies** – installing the required libraries for WPILib integration.
* **Basic Code** – example code to verify operation and start development.
